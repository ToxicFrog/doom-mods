# ⚠ THESE ARE NOT THE STABLE BUILDS ⚠

The files in this directory are the latest *unstable* builds of the mods. If you
are looking for the latest *stable* release, go to the
[releases page](/ToxicFrog/doom-mods/releases) and search for the mod you are
interested in.

If you are here for UZArchipelago, remember that unstable builds of the apworld
usually *will not work* with stable releases of the pk3 (and vice versa).
